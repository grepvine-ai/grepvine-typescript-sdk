# Security policy

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Report them privately through GitHub: on this repository's **Security** tab,
choose **Report a vulnerability**. Include the SDK version, a description of
the problem and, if you can, steps to reproduce it. We will acknowledge the
report and keep you informed while we fix it.

This policy covers the Grepvine TypeScript SDK. Vulnerabilities in the Grepvine
service itself can be reported the same way.
